# Colab-specific variant of requirements.txt.
#
# Differences from requirements.txt, both learned the hard way in the
# 2026-09-16 Colab GPU session (see docs/colab-gpu-plan.md and
# colab/colab_gpu_eval.ipynb for the full narrative):
#
# 1. pywin32 dropped entirely -- Windows-only, has no Linux build. Left in
#    requirements.txt line 24 above the Phase 1/2/3/4/5 blocks meant pip
#    aborted there and silently never installed rank-bm25, sentence-
#    transformers, torch, pytest, streamlit, or openai below it.
# 2. torch and torchvision dropped from this file -- requirements.txt pins
#    torch==2.14.0 from a Windows CPU-only pip freeze. Installing that in
#    Colab clobbers the CUDA-matched torch/torchvision pair Colab ships
#    preinstalled (torch 2.11.0+cu128 / torchvision 0.26.0+cu128), and
#    hunting for a torch==2.14.0-compatible torchvision on the cu128 index
#    doesn't reliably resolve (pip fell back to torchvision==0.2.0 from
#    2018 when tried). Leaving both out of this file means pip won't touch
#    Colab's preinstalled, already-GPU-verified pair.
#    If Colab's preinstalled torch/torchvision are ever missing/broken,
#    reinstall the known-good matched pair explicitly:
#      pip install torch==2.11.0+cu128 torchvision==0.26.0+cu128 \
#        --index-url https://download.pytorch.org/whl/cu128
#    (version numbers are whatever Colab's own conflict warnings report at
#    the time -- check `pip show torchvision` before assuming 2.11/0.26
#    still applies to a future Colab image.)
# 3. accelerate added -- not in requirements.txt at all, but transformers
#    5.x's PreTrainedModel lazy-import chain needs it importable even for
#    pure-text models; without it you get a generic
#    "ModuleNotFoundError: Could not import module 'PreTrainedModel'"
#    that gives no hint accelerate is the actual missing piece.
# 4. jedi added -- ipython (preinstalled in Colab) wants jedi>=0.16 but
#    Colab doesn't ship it; pip's resolver flags this as a warning, not a
#    hard failure, but it's cheap to silence.
# 5. pandas relaxed to >=2.2.3 (not pinned to requirements.txt's 3.0.5) --
#    google-colab's own package pins pandas==2.2.3; forcing 3.0.5 produces
#    a resolver conflict. Streamlit/pandas (Phase 4 UI) aren't exercised by
#    the eval scripts this notebook runs anyway.
